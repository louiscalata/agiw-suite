TYPE ONLY · The name AGIW is set in Inter. Provisional, not a font Louis chose. D4 Split is rejected.

Inter is licensed under the SIL Open Font License 1.1. If Inter is absent, the stack uses Liberation Sans, then Noto Sans. Weight 600. Tracking is 0.02em on top of the font’s own kerning. The tab icon is the letters AG, because the full word does not fit at that size. The earlier split-block files stay in jaryo/marks/ and are not used.
