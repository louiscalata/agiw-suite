AGIW

The name is the identity. There is no separate symbol.

Typeface
IBM Plex Sans for text. IBM Plex Mono for numbers, IDs, and code. If Plex is absent, Liberation Sans, then Noto Sans.
Tab icon
The favicon is the letters AG, because the full word does not fit at that size.
Rejected
D4 Split is rejected. The earlier split-block files stay in jaryo/marks/ and are not used.
Surface
Ink for readings. Booklet red for headlines and the wordmark.
Typeface notes

TYPE ONLY · The name AGIW is set in IBM Plex Sans. The favicon outlines are Inter. D4 Split is rejected.

IBM Plex Sans and IBM Plex Mono are licensed under the SIL Open Font License 1.1. Inter, used for the favicon outlines, is licensed under the SIL Open Font License 1.1. If Plex is absent, the stack uses Liberation Sans, then Noto Sans. The tab icon is the letters AG, because the full word does not fit at that size. The earlier split-block files stay in jaryo/marks/ and are not used.
