    Check steps
    What this does

    Pressing Fix inference checks and repairs the Mac runtime, Windows route and Nisi Inference in one guarded run. Opening this panel from the inspector makes no repair request; press Run check below to start the same repair. The repair checks the Mac runtime, Nisi Inference and the Windows route once each, in that order. Local runtime may start the Mac loopback model server. Nisi Inference may clear a stuck Nisi call record through the launcher's own recover, only after it proves nothing is running. Route may reconcile exact pending records, force-unmount and remount a stuck or missing SharedChami share, and then send one short Windows model request.

    Local runtime never runs a model. Route sends one short Windows request only after every owner check is clear, and never while another Windows job is open. It does not verify answer quality. Nisi Inference never calls, loads or unloads a model, sends work to Nisi or Jev, or touches the PC.
