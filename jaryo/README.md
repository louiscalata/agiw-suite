# Jaryo seam

Shared, framework-neutral tokens, theme resolution, primitives, and marks for AGIW Suite. OPOS and Nisi can use this folder later. This checkout does not modify those repositories and does not publish a package.

AGIW decisions recorded here:

- Strict black and white. No graphite, copper, or color accent in AGIW.
- System light/dark is the default. Light or Dark in the theme control is an explicit override.
- Factory structure, quiet surfaces, balanced density, expandable evidence detail.
- Persistent desktop sidebar. Overview, map, components, and identity stay reachable on a small screen.
- Motion is for schematics and transitions. It is not false telemetry. Reduced motion removes that motion.
- The app opens on Overview.
- Logo selection is pending. D1 Stamp is only the provisional mark on the chrome.
- `appliedChoiceFile` is null. `chosenFamilyIds` is empty. Do not infer option ids.

`c92dab2` is historical. A later verified head supersedes it. Receipts stay in `docs/data/`. They are not a pass on the current head.
