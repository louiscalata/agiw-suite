# AGIW Android monitor

Read-only client for a person-supplied observer address. It does not ship a credential, a sample snapshot, or a repair control.

The desktop Mac and Windows observers stay on `127.0.0.1`. This module is not part of those installers.

## Flip 6

Samsung lists the cover at 3.4 inches, 720×748, 60 Hz, and the inner display at 6.7 inches, 2640×1080. Android does not place an ordinary activity on the cover by itself. One UI can show a short Labs list, and Good Lock MultiStar can launch other apps there. This app only switches to the square layout when the window itself is nearly square.

## Build

`android/monitor-core/check.sh` compiles and runs without the Android SDK.

The app module needs the Android SDK and Gradle. This checkout does not vendor either. If they are absent, the APK is not produced.
