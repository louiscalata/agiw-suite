## Open gates

These are not closed by v1.1.0. Do not describe 1.1.0 as accepted on these points.

- **Native macOS GUI is untested on hardware.** This tree was exercised as the loopback Python observer in a Linux VM. That is not a Developer ID build, not a quarantined Mac install, and not the Swift menu-bar app. Complete native rendering, a clean-Mac first install, and the Jev credential dialogs remain open, as already recorded for the 1.0.0 (7) download.
- **Windows MSI service / OSMF EULA decision is on HOLD, and a POST ROLLBACK finding is open.** The checkout records that WiX was not present, that installing a toolchain would not be MSI or service acceptance, and that PC POST ROLLBACK remains open (`docs/development.md`, acceptance ledger in `web/monitor-tabs.mjs`). No MSI is produced here. The OSMF EULA decision is not in this repository; it stays on HOLD until Louis decides it.
- **Galaxy Z Flip6 inner and cover screens are untested on a device.** `android/README.md` records no physical Flip 6 and no cover host. A nearly square window is not proof of the cover. v1.1.0 does not install or change the Android UI on a device.

## Bundled Nisi

AGIW pins public Nisi **0.2.0**, not a floating branch.

- Manifest: `vendor/nisi/manifest.json` — version `0.2.0`, tag `v0.2.0`, commit `41fb6aeb67713011abc40b1434f5a939a5704aa4`, archive SHA-256 `aa46147005814c4e72aaa87099894552122ebe2bed91dad89a61b61388be3737`.
- `bundle_nisi.py` checks that manifest's SHA-256 (`d7cd9f31365ad47f01ccfbfaf2cf29923830abf642c60518cbeb1b9776d8cd23`) and every file hash.
- `bundled_components.py` repeats the version string `0.2.0`.

Nothing here moves that pin. After Nisi **v0.3.1** is tagged, update the manifest (version, commit, archive URL, archive bytes, archive SHA-256, and each file hash), replace `vendor/nisi/package/` with that release's bytes, and recompute the manifest hash in `bundle_nisi.py`. Then update the `0.2.0` checks in `bundled_components.py` and the tests that expect version `0.2.0`. Leave `nisi_v02.py`'s private identity `0.2.0-private.0` alone unless that private runtime is part of the same tag.
