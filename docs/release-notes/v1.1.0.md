# AGIW Suite 1.1.0

This is a source release. It has no Mac app to download.

The signed app to install is still **1.0.0 (7)** for Apple silicon, macOS 13 or later:

**[Download 1.0.0 (7)](https://github.com/louiscalata/agiw-suite/releases/download/v1.0.0/AGIW-Inference-Monitor-1.0.0-7-arm64.zip)** · [v1.0.0 notes](https://github.com/louiscalata/agiw-suite/releases/tag/v1.0.0) · [SHA256SUMS.txt](https://github.com/louiscalata/agiw-suite/releases/download/v1.0.0/SHA256SUMS.txt)

Prepared 9 November 2026 from `main` at `f8b2dc75`, then tagged `v1.1.0` and published the same day. Building this tag does not reproduce the 1.0.0 ZIP.

## Not yet tested

These points are still open. Do not describe 1.1.0 as tested on these.

- The Mac app built from this source has not been tested on a Mac. The checks that were run used the loopback Python observer in a Linux VM. That is not a signed Mac build, not a first install on a clean Mac, and not the menu-bar app. The Jev credential dialogs are also untested, as they were for the 1.0.0 (7) download.
- The Windows installer has not been released. No Windows installer is produced from this tag. The Windows code in the repository is a preview.
- The Android monitor has not been tested on a physical Galaxy Z Flip6. A nearly square window is not the cover screen. This tag does not install the Android app on a phone.

## Bundled Nisi

AGIW pins public Nisi **0.2.0**, not a floating branch.

- Manifest: `vendor/nisi/manifest.json` — version `0.2.0`, tag `v0.2.0`, commit `41fb6aeb67713011abc40b1434f5a939a5704aa4`, archive SHA-256 `aa46147005814c4e72aaa87099894552122ebe2bed91dad89a61b61388be3737`.
- `bundle_nisi.py` checks that manifest's SHA-256 (`d7cd9f31365ad47f01ccfbfaf2cf29923830abf642c60518cbeb1b9776d8cd23`) and every file hash.
- `bundled_components.py` repeats the version string `0.2.0`.

Nothing here moves that pin. After Nisi **v0.3.1** is tagged, update the manifest (version, commit, archive URL, archive bytes, archive SHA-256, and each file hash), replace `vendor/nisi/package/` with that release's bytes, and recompute the manifest hash in `bundle_nisi.py`. Then update the `0.2.0` checks in `bundled_components.py` and the tests that expect version `0.2.0`. Leave `nisi_v02.py`'s private identity `0.2.0-private.0` alone unless that private runtime is part of the same tag.
