# App Store edition app icon

`AppIcon.appiconset` is generated by `brand/build-icons.py` from the same master as the full monitor's icon:
the letters AG in Inter SemiBold, white on a black rounded square.

To apply it to a copy of the native wrapper, replace the wrapper's `App/Assets.xcassets/AppIcon.appiconset`
with this folder. Do not apply it to a dirty checkout. The file names and `Contents.json` match the wrapper's
existing set, so the Xcode project needs no change.

The wrapper's menu-bar icon is drawn by its own Swift source, which is not in this repository; it still uses
system symbols until that source changes.
